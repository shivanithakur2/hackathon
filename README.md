# Smart Campaign - DoorDash Design

A pixel-perfect implementation of the Smart Campaign M3 design from Figma.

## 🌐 Live Demo

Visit the live site: [View Demo](https://YOUR_USERNAME.github.io/smart-campaign-demo/)

## ✨ Features

- **Navigation Bar** - Clean header with DoorDash branding
- **How It Works** - Interactive collapsible sections explaining the campaign
- **Settings Section** - Configure stores, scheduling, budget, and more
- **Live Preview** - Real-time preview of campaign promotions
- **Campaign Estimates** - View projected costs, sales, and ROI

## 🛠️ Tech Stack

- HTML5
- CSS3
- Vanilla JavaScript
- Figma Design System

## 📱 Design

Built from Figma design file: [Smart Campaign M3](https://www.figma.com/design/SmWlyNwCUziM2qTiy1bkgD/Smart-Campaign-M3)

## 🚀 Getting Started

1. Clone this repository
2. Open `index.html` in your browser
3. That's it! No build process needed.
