How to Use

Method 1: Simple Image Tag

<img src="icons/dashboard-line-24.svg" alt="Dashboard" width="24" height="24">
Dashboard icon using img tag

Method 2: With Color Filters (CSS)

Red (#EB1700)
Green (#00832D)
Gray (#606060) 
/* CSS for colored icons */
.icon-red {
    filter: invert(21%) sepia(98%) saturate(6088%) 
            hue-rotate(0deg) brightness(96%) contrast(112%);
}

.icon-green {
    filter: invert(39%) sepia(97%) saturate(466%) 
            hue-rotate(92deg) brightness(92%) contrast(101%);
}

Method 3: Inline SVG (Best for CurrentColor)

Note: For this method, you'll need to copy the SVG code directly from the .svg file

<svg fill="currentColor" width="24" height="24" viewBox="0 0 24 24">
    <!-- paste SVG path here -->
</svg>

Method 4: Navigation Menu Example

<div class="nav-menu-item">
    <img src="icons/dashboard-line-24.svg" alt="" width="24" height="24">
    <span>Dashboard</span>
</div>
